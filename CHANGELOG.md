# Changelog

## 0.1.0 — 2026-08-13

- Public transport-independent ABCM workspace, ScopeMap, domain-language, skill-resolution, and context-bundle library.
- MCP 2025-11-25 resources/tools over stdio and authenticated Streamable HTTP.
- Authenticated REST file/workspace/context/documentation API with deterministic OpenAPI 3.1.
- Rebuildable SQLite schema v8 with fencing, atomic map publication, documentation recovery, body-free bundle/fingerprint catalog, and nullable artifact worker metadata.
- One-way mounted-directory/Obsidian mirror, identity-preserving moves, tombstones, and operator-approved managed cutover.
- Request limits/cancellation, strict data-only YAML, oversized-index protection, fixed body-free audit/metrics, threat model, benchmarks, SBOM, and runnable examples.
- Placement validation for agent roles, artifacts, and architecture documents, plus API-level immutable accepted ADR/RFC content with checksum-preserving rename.
- Machine-checked release traceability for all 78 baseline requirements, 22 baseline acceptance scenarios, 196 extension requirements, and 56 extension acceptance scenarios.

Known non-goals are distributed multi-writer coordination, external identity providers, automatic two-way sync, script execution/activation, LLM execution, and Node.js runtime support for the Bun SQLite reference adapter.
